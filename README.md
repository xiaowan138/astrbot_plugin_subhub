# 统一订阅推送中心 (astrbot_plugin_subhub)

一站式订阅推送 AstrBot 插件：聚合 **12 类内容源 + 任意 RSS/Atom**，按设定时间/间隔自动推送到群聊或会话，Pillow 渲染成美观的图片卡片。

## 内容源（13 类）

| 分类 | 来源 | 说明 |
|---|---|---|
| 热搜榜 | 🔥 微博热搜 / 🍃 百度热搜 / 💙 知乎热榜 / 🎵 抖音热搜 / 📰 腾讯新闻热榜 / 🎬 B站热门 / 💼 36氪热榜 | 榜单卡片，带热度 |
| 信息列表 | 🎮 Steam特惠 / 🍙 今日更新番剧 / 🐙 GitHub Trending / 🟠 Hacker News / 💬 V2EX热门 | 摘要卡片，带折扣/话数/星数/回复数 |
| RSS | 📰 任意 RSS/Atom | 自动去重，卡片带摘要行 |

## 命令一览

### 订阅管理
| 命令 | 说明 |
|---|---|
| `/订阅 <源>` | 添加订阅，如 `/订阅 微博热搜` |
| `/订阅 <源> 关键词:词1,词2` | 带关键词过滤，只推标题命中的条目（如 `/订阅 微博热搜 关键词:原神,崩铁`） |
| `/订阅 rss <链接>` | 订阅任意 RSS/Atom，如 `/订阅 rss https://www.ruanyifeng.com/blog/atom.xml` |
| `/我的订阅` | 查看订阅清单（含调度状态、关键词、独立调度标记） |
| `/退订 <编号>` | 按编号退订，也可 `/退订 名称关键词` |
| `/查看 <源>` / `/查看 <编号>` | 立即抓取推送一次（内置源无需订阅也能看） |
| `/订阅关键词 <编号> 词1,词2` / `off` | 修改/清除某订阅的关键词过滤 |
| `/订阅开关 <编号> on\|off` | 单独启停某个订阅（也是自动暂停后的恢复入口） |

### 调度设置（管理员）
| 命令 | 说明 |
|---|---|
| `/订阅间隔 HH:MM` | 每天定时推送，如 `/订阅间隔 08:00`（支持 `8:00` 写法，自动规范） |
| `/订阅间隔 40` | 每 40 分钟轮询推送 |
| `/订阅间隔 off` | 关闭本会话自动推送 |
| `/订阅间隔 <编号> HH:MM\|分钟\|off` | 某个订阅独立调度（off = 恢复跟随群设置） |
| `/订阅汇总 HH:MM` / `off` | 每天一张汇总卡片（所有来源各取前几条合并成一张图；独立调度的订阅不进汇总） |
| `/推送暂停` / `/推送恢复` | 本会话级暂停/恢复 |
| `/推送总开关 on\|off` | 全局总开关（所有会话） |

### 其他
| 命令 | 说明 |
|---|---|
| `/订阅导出` | 导出本会话订阅 JSON |
| `/订阅导入 <JSON>` | 导入订阅（管理员） |
| `/订阅测试` | 一键逐个测试全部 13 类来源的抓取+渲染+发送，输出成功/失败清单 |
| `/订阅帮助` | 命令帮助 |

## 特色功能

- **关键词过滤**：订阅时附加 `关键词:词1,词2`，仅推送标题命中的条目（热搜监控利器）
- **每日汇总卡片**：`/订阅汇总 08:00`，多个来源合并成一张图，不再刷屏
- **订阅级独立调度**：重要来源可以高频（如每 10 分钟），其他保持默认
- **静默时段**：配置 `quiet_hours = 23:00-07:00`，夜间不打扰；汇总落在夜间时出静默后自动补发
- **失败自愈**：某订阅连续失败 N 次（默认 5，可配置）自动暂停并在会话内通知，`/订阅开关 <编号> on` 恢复并重置计数
- **明暗主题**：配置 `theme = dark | light`
- **多级开关**：全局总开关 → 会话暂停 → 单订阅开关
- **重启不失效**：调度器随插件加载自动启动，重启 AstrBot 后定时推送照常

## 配置项（Web 面板 → 插件配置）

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable_auto_push` | true | 全局自动推送总开关 |
| `default_interval_min` | 30 | 默认轮询间隔（分钟） |
| `min_interval_min` | 10 | 最小间隔下限 |
| `weibo_top_n` | 20 | 内置源卡片条数（1-50） |
| `digest_top_n` | 3 | 汇总卡片每来源条数（1-10） |
| `theme` | dark | 卡片主题 dark / light |
| `quiet_hours` | （空） | 静默时段，如 `23:00-07:00` |
| `quiet_catchup` | true | 静默结束后补发汇总 |
| `auto_pause_after_fails` | 5 | 连续失败自动暂停阈值（0=关闭） |

## 安装

1. 将本插件放入 `AstrBot/data/plugins/astrbot_plugin_subhub/`
2. 安装依赖：`pip install -r requirements.txt`（aiohttp、Pillow）
3. 重启 AstrBot，面板确认插件已加载（图标读取目录下 `logo.png`）
4. 群里发送 `/订阅测试` 一键验证全部来源

## 工程说明

- 抓取全部走 aiohttp 异步，内置全局限流（间隔 1.5s，微博 3s）防风控
- 持久化：`data/astrbot_plugin_subhub/subs.json`（原子写 + 线程锁，损坏自动备份）
- 全程异常兜底：任何单点错误只记日志，绝不影响宿主机器人
- 图片发送：Pillow 渲染 PNG → base64 → AstrBot Image 组件

## 已知行为

- 命令需空格分隔参数（`/订阅微博` 不会被识别，需 `/订阅 微博`）
- 抓取器全局限流 1.5 秒/请求：订阅很多时一轮推送会串行排队，属正常现象
- 知乎/抖音等接口来自官方前端页面所用 API，若官方调整可能需要更新解析
