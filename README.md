# 统一订阅推送中心 (astrbot_plugin_subhub)

一站式订阅推送插件，把 **7 类内容源** 聚合到一起：微博热搜、百度热搜、腾讯新闻热榜、B 站热门、Steam 特惠、今日更新番剧，以及任意 **RSS/Atom**。定时或手动自动推送到你的群聊 / 会话，并用 Pillow 渲染成美观的图片卡片。

## ✨ 功能

- 🔥 **热搜榜单**：微博热搜、百度热搜、腾讯新闻热榜、B 站热门 —— 带热度/播放量的榜单卡片
- 🎮🍙 **信息列表**：Steam 限时特惠、今日更新番剧 —— 更新摘要卡片
- 📰 **RSS/Atom**：订阅任何博客、新闻、播客，新更新自动推送去重后的摘要卡片
- ⏰ **定时推送**：每日 `HH:MM` 定时，或按分钟间隔轮询
- 🔘 **多级开关**：全局总开关 + 群级暂停/恢复，随时启停自动推送
- 🧪 **一键测试**：`/订阅测试` 逐个抓取验证全部来源可用性
- 🖼️ **图片卡片**：Pillow 渲染，中文字体自动探测（微软雅黑/黑体/苹方等）
- 🛡️ **健壮**：全程 try/except、线程锁 + 原子写、去重记忆，崩不坏 AstrBot

## ⚡ 快速开始

1. 把本目录放到 `AstrBot/data/plugins/astrbot_plugin_subhub`
2. 安装依赖：`pip install -r requirements.txt`
3. 重启 AstrBot

## 🧭 命令

### 订阅管理
| 命令 | 说明 |
| --- | --- |
| `/订阅 微博热搜` | 订阅微博热搜（百度/腾讯/B站/Steam/番剧 同理） |
| `/订阅 rss <链接>` | 订阅任意 RSS/Atom（如 `/订阅 rss https://www.ruanyifeng.com/blog/atom.xml`） |
| `/我的订阅` | 查看已订阅列表与编号 |
| `/退订 <编号>` | 按编号移除订阅 |
| `/查看 <源>\|编号` | 立即抓取并推送一次（手动触发） |

### 定时 / 开关（管理员）
| 命令 | 说明 |
| --- | --- |
| `/订阅间隔 HH:MM` | 设置每天定时推送时间 |
| `/订阅间隔 40` | 改为每 40 分钟轮询 |
| `/订阅间隔 off` | 关闭定时推送 |
| `/推送总开关 on\|off` | **全局**自动推送总开关（所有会话） |
| `/推送暂停` | 只暂停**本会话**自动推送 |
| `/推送恢复` | 恢复本会话自动推送 |
| `/订阅测试` | 一键逐个抓取并推送全部 7 类来源，验证可用性 |

> 手动 `/查看`、`/订阅测试` 权限开放给群成员；定时/间隔/总开关/暂停恢复仅管理员。

## ⚙️ 配置

在插件 Web 配置面板可设置（以下为默认值）：

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enable_auto_push` | bool | `true` | 全局自动推送总开关（可用命令切换） |
| `default_interval_min` | int | `30` | 新订阅默认推送间隔（分钟） |
| `min_interval_min` | int | `10` | 允许的最小推送间隔（分钟） |
| `weibo_top_n` | int | `20` | 热搜榜类卡片条数（1-50） |

## 🗂️ 数据位置

- 订阅配置存于 `AstrBot data/plugin_data/astrbot_plugin_subhub/subs.json`（原子写 + 线程锁）

## 📝 说明

- 内置源使用公开接口抓取，若某源接口临时不可用，只会记录日志并跳过，不影响其他源。
- 定时推送依赖机器人常驻运行。
- 不同平台（QQ/飞书/Telegram 等）的卡片渲染与图片组件行为略有差异。
